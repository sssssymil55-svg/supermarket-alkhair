# سوبر ماركت الخير — النسخة المطوّرة v3

هذه حزمة مشروع جاهزة للتهيئة والنشر على Cloudflare Workers + D1. تتضمن واجهة عربية RTL بألوان أخضر وبرتقالي وكتابة سوداء، متجر منتجات، سلة وطلبات نقداً عند الاستلام، ولوحة إدارة للمنتجات والطلبات.

## مهم قبل النشر
هذه الحزمة **ليست منشورة تلقائياً** على رابطك الحالي. يجب ربطها بحساب Cloudflare وقاعدة D1 ثم نشرها. لا أستطيع الدخول إلى حسابك أو تحديث الرابط الحالي من داخل هذه الحزمة.

## إعداد سريع
1. فك ضغط الملف على جهاز كمبيوتر.
2. من Cloudflare Dashboard أنشئ قاعدة D1 باسم `alkhair-store-db`.
3. نفّذ محتوى `migrations/0001_init.sql` على قاعدة البيانات الجديدة.
4. انسخ `database_id` إلى `wrangler.toml`.
5. انقل ملفات `index.html`, `styles.css`, `app.js`, `manifest.json`, `icon.svg`, `sw.js` إلى مجلد `public/` (أنشئ المجلد إن لم يكن موجوداً). تأكد أن `public/index.html` هو واجهة المتجر وليس ملف التهيئة.
6. من مجلد المشروع ثبّت Wrangler ثم نفّذ:
   - `npm install -D wrangler`
   - `npx wrangler secret put ADMIN_PIN` ثم أدخل رمز الإدارة الخاص بك.
   - `npx wrangler secret put ADMIN_TOKEN` ثم أدخل قيمة طويلة عشوائية سرية (32 حرفاً أو أكثر).
   - `npx wrangler deploy`
7. بعد النشر افتح رابط Worker واختبر `/api/health`.

## الأمان
- لا تضع `ADMIN_PIN` أو `ADMIN_TOKEN` داخل ملفات الواجهة أو `wrangler.toml`.
- غيّر رمز الإدارة قبل النشر. رمز افتراضي غير مضمّن.
- لا تشارك `ADMIN_TOKEN` مع أي شخص.
- الطلبات تحفظ مركزياً في D1، وتظهر في لوحة الإدارة بعد تسجيل الدخول.

## ملاحظات
- السعر بالدينار العراقي كعدد صحيح.
- التوصيل ثابت 1,000 د.ع.
- إضافة صورة تكون عبر رابط صورة عام HTTPS.
- السلة تحفظ محلياً على جهاز الزبون، أما الطلب النهائي فيُحفظ في قاعدة D1 المشتركة.
- هذه نسخة أساسية عملية؛ اختبرها قبل الاعتماد التجاري. قبل التشغيل الفعلي يوصى بإضافة حماية من الطلبات الآلية ومراجعة صلاحيات الإدارة وحدود المخزون.
